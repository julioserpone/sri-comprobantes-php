# Checklist de release

- [ ] `main` actualizado y árbol limpio.
- [ ] Versión decidida (SemVer).
- [ ] `CHANGELOG.md` actualizado con fecha.
- [ ] `composer validate --strict`.
- [ ] `composer check` verde (cs, PHPStan, PHPUnit).
- [ ] Sin secretos, certificados ni XML reales.
- [ ] Tag anotado creado.
- [ ] Tag empujado.
- [ ] Workflow Release verde.
- [ ] `gh release view` muestra notas correctas.
- [ ] Documentación/enlaces actualizados.
